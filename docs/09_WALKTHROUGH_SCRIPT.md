## Q&A preparation

| Likely question | Short answer | Where to show it |
|---|---|---|
| "How does 71% become rupees?" | A logistic model on corridor rain features, Platt-calibrated against simulated outcomes. Then EV: p × (loss if nothing − loss if act) against an action cost that is paid either way. We show p* next to p. The calibration is honestly labelled internal, not real-world. | Early Warning tooltip; `02_ARCHITECTURE.md` §8 |
| "Is the truck location from satellites?" | No. GPS is the truck's own telemetry. We cross-validate it against the road network, the last trusted position, kinematics, weather/alerts and gate scans. | Trust card "Geospatial / road-network match" |
| "Couldn't an attacker fake many trucks?" | Yes, so the blockage inference uses a trust-weighted quorum and requires independent corroboration. BM-10 proves zero false reroutes. | Benchmark BM-10 |
| "Does the AI make decisions?" | No. OR-Tools decides. The LLM only narrates, every number it outputs is checked against the optimizer output, and it falls back to a template. | Why This Plan: "numbers validated ✓" |
| "Is any of this real data?" | The network and telemetry are synthetic (labelled). Weather and alerts are LIVE with a REPLAY fallback. AIS is REPLAY. The flood mask is MOCK. | Badges everywhere |
| "Does it scale?" | Entity-partitioned streams and stateless workers. Show the L4 load-test result and Grafana. | Grafana, `08_EVALUATION_FRAMEWORK.md` §6 |
